Локальное S3
Silo (поддерживаемая ветка MinIO), образ закреплён по версии и digest.
AWS SDK S3Client, явный локальный endpoint/region/credentials, path-style requests.
PostgreSQL — метаданные/outbox; приватный S3 bucket order-files — bytes.
В Kafka только идентификаторы и версии; содержимое файлов в Git/Kafka не передаётся.
Отдельная Docker-сеть, loopback-only API/console, отдельный scoped File credential.
Консоль localhost:19001, вход проверен (204), анонимный bucket отвергается (403).

Старые 4 объекта, включая DELETED, перенесены без изменения метаданных/связей.
Размер/SHA-256 сверены с PG для каждого. Старый volume оставлен read-only.
Flyway V2 хранит completion marker; повторяемый перенос и повреждённый источник
проверены в IT. Настоящий S3/Testcontainers: round-trip, права, rollback,
checksum, недоступность и восстановление. Файлового fallback нет.

Runtime config
Git — источник значений; Spring Cloud Bus Kafka — сигнал перечитать конфигурацию.
Девять приложений подключены к runtime-config-events: 3 partitions/RF3/minISR2.
Bus использует byte serializers, бизнес-каналы сохраняют string serializers.
FilePolicy атомарно применяет max-bytes/MIME, отвергает невалидный набор;
соединения/ключи/bucket/hard transfer bound меняются при перезапуске.
Settings API только SUPERVISOR; refresh — отдельный локальный Config operator.
Без credentials refresh=401; busenv=403; helper передаёт application/json.
